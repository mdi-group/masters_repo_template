# Results and run records

Keep concise summaries and the records needed to interpret reported results here. Per-run files in `results/runs/` are ignored by Git by default; keep large outputs in approved storage and commit small, useful summaries when appropriate.

For a substantial run, copy [`../templates/experiment_record.yml`](../templates/experiment_record.yml), fill it in, and save the record alongside its outputs or in a tracked project record. Include input IDs and versions, code commit, exact command/configuration, environment, and output location. Do not delete unsuccessful runs if they affect how a result should be interpreted.
