# Scripts

Keep reusable analysis, data-processing, and figure-generation code here. Give files descriptive names and include a short usage note at the top of each script or in a nearby README.

For each important script, document:

- What it reads and where those inputs are described in `data/manifest.csv`.
- What it writes and where the outputs are recorded.
- How to run it, including arguments, configuration, and random seed where relevant.
- Required software versions or environment file.

Avoid hard-coded paths to your personal computer. Keep exploratory notebooks in `notebooks/`; move steps needed to reproduce final results into scripts or clearly documented notebooks.
