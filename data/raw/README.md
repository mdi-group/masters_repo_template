# Raw data

Keep original, unmodified input data here only when local storage is appropriate. This folder's contents are ignored by Git by default. Do not remove that protection or upload files until you have checked file size, licence, privacy/consent conditions, and supervisor approval.

For every source, add a row to [`../manifest.csv`](../manifest.csv) with its origin, version/date, access conditions, and SHA-256 checksum. If files live in approved institutional or external storage, record the stable location and access steps there. Never overwrite the original with a cleaned or transformed copy.
