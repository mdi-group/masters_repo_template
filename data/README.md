# Data

Use `raw/` for original, unmodified data and `processed/` for derived files. The data payloads are ignored by Git by default, so they will not be uploaded accidentally.

Record the source, version or date, access conditions, and how to obtain each dataset here or in a short README next to the data. For processed data, note which script and settings produced it. Use approved storage for large or restricted files, and do not overwrite the original data.
